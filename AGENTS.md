# AGENTS.md – Nikhaar

Online cosmetics shop with UPI + UTR payment verification and a separate admin panel. **Read PLAN.md first and continue from the next unfinished milestone.**

## Architecture
- TanStack Start + React 19, file-based routes in `src/routes/` (`routeTree.gen.ts` is generated by the build).
- Tailwind v4. Theme tokens (plum/blush/gold/cream, Fraunces + Plus Jakarta Sans) and component classes (`btn-primary`, `btn-ghost`, `btn-wa`, `input`, `label`, `card`, `chip`) live in `src/styles.css`.
- **Data (milestone 1):** `src/data/fixtures.ts` holds all types and sample data. `src/lib/store.ts` is a `useSyncExternalStore` browser store saved to localStorage. UI reads with `useStore()` and writes only through `actions.*`, which return `{ ok, value | error }`. To move to Netlify Database (milestone 2), turn the actions into server functions and keep their names and signatures.
- The store loads from localStorage in a `useEffect` in `__root.tsx` (`hydrateStore`). Until then `state.ready` is false, so pages that need a session show "Loading…". This avoids hydration mismatches.

## Key directories
- `src/routes/` – storefront: `index`, `products/$productId`, `cart`, `checkout`, `order-success`, `login`, `account` (tabs via `?tab=`), `support`.
- `src/routes/nikhaar-admin.tsx` – admin layout + login gate (noindex). Children in `src/routes/nikhaar-admin/`: dashboard, orders, `products.index`/`products.$productId` (`new` = create), `customers.index`/`customers.$userId`, staff, settings.
- `src/components/Shop.tsx` – header/footer/layout, ProductCard, Price, Stars, StatusChip, Modal, CancelDialog, UpiQr, WhatsApp button.
- `src/components/admin.tsx` – `useAdmin()` (role: owner/staff), `PageTitle`, `OwnerOnly`.
- `src/lib/format.ts` – `inr`, dates, `img()` (Image CDN for `/img/*`, data URLs pass through), `waLink`.
- `src/lib/files.ts` – resize uploads to JPEG data URLs.
- `public/img/` – generated product/lifestyle photography.

## Rules & decisions
- Roles: **owner** can do everything. **Staff** can add/edit products and stock and view orders and customers. They cannot approve or cancel orders, block users, reset passwords, manage staff, or change shop settings (they can change their own password).
- A UTR must be 12 digits and unique across all orders. Stock is reserved when an order is placed and restored when it is cancelled.
- Every cancellation stores a reason and who cancelled it (`customer` | `admin`). Customers see this reason in their account.
- The admin URL is `/nikhaar-admin` and is intentionally not linked from the storefront.
- Always load images through `img(src, width)`.
- Passwords are plain text in milestone 1 sample data only. Milestone 3 must hash them and enforce roles on the server.
